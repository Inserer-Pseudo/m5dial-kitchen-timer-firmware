Installer

Environ une minute. Le Dial redémarre tout seul à la fin.

  1. Un ordinateur avec Google Chrome ou Microsoft Edge L’installation passe par Web Serial : ni téléphone, ni Firefox, ni Safari.
  2. Un câble USB-C de données Certains câbles ne font que la charge : si aucun port n’apparaît, essayez-en un autre.
  3. Allumez l’écran, puis branchez Réveillez le Dial (bouton ou molette) avant de le relier à l’ordinateur : en veille, son port USB n’apparaît pas.
  4. Cliquez sur « Installer » et choisissez le port Il s’appelle en général « USB JTAG/serial debug unit » suivi d’un numéro de port.
  5. Laissez « Erase device » décoché La fenêtre d’installation est en anglais. Sans effacement, les réglages, le Wi‑Fi et les minuteurs restent sur le Dial. Cochez « Erase device » (effacer l’appareil) uniquement pour revenir à l’état d’usine.
Ce navigateur ne peut pas installer le firmware. Ouvrez cette page dans Google Chrome ou Microsoft Edge sur un ordinateur (Windows, macOS, Linux ou ChromeOS). Si vous y êtes déjà, une stratégie d’entreprise bloque peut-être Web Serial : essayez depuis un autre ordinateur.
Connexion non sécurisée. Le navigateur n’autorise l’accès USB que sur une page HTTPS : ouvrez la page officielle.
Le firmware n’a pas pu être chargé. Une nouvelle version est peut-être en cours de publication : réessayez dans quelques minutes. Si le problème persiste, la page des versions indique l’état du projet.

Et ensuite ?

Une fois le Wi‑Fi configuré sur le Dial (Réglages › Wi‑Fi), les nouvelles versions arrivent toutes seules : le minuteur vérifie au plus une fois par jour, quand il est allumé et inutilisé, et ne s’installe qu’après votre confirmation, jamais pendant une alarme.

Un problème ?

  • Aucun port dans la liste : autre câble, autre prise USB, écran allumé avant de brancher.
  • Port occupé : fermez les autres logiciels qui l’utilisent (moniteur série, Arduino IDE…).
  • Installation interrompue : débranchez, rallumez l’écran, rebranchez et recommencez.

Authenticité

Chaque version est signée (RSA-3072). Le Dial refuse toute mise à jour qui n’est pas signée avec la clé du projet. Vérifier un binaire
